# Sociable

This is a social media web application that connects to the Noroff Api

## Link to livedemo:

https://furuknappen.github.io/js2-camilla-furuknappen-larsen/

## How to use the app

Open livedemo and register a user by creating an email that ends in "@stud.noroff.no"

## Info about the API

This is a school API, so be respectful and kind

## Made using

- TypeScript
- HTML
- CSS / Tailwind

## Features

- Register and login function
- View all posts and single post
- Create, update and delete post
- Comment on a post
- Reply to a comment
- Delete your comment
- View profilepage
- Search for a post

## Purpose

This website was made as an assignment form Noroff University as a way to learn about how to connect to the Noroff API.
The goal for this project was to learn how to connect with an API and using get, put, post, delete. The Design, UX and accessibility was not a priority in this assignment

## Prerequesites

- Node.js to run npm
- Git
- VSCode, or equivalent

## Setup

Clone the repository

git clone https://github.com/IngerMathildeEiklund/js2-ca.git
cd js2-ca

## Install dependencies

`npm install`

## Environment Variables

To run this project, you will need to add the following environment variables to your .env file:

`VITE_API_KEY`

## Scripts

To start the server:

`npm run dev`

Type-check and build for production:

`npm build`

Preview the production build:

`npm run preview`

## Code Formatting. Eslint & Prettier

- `bash`
- `npm run lint`
